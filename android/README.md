# geoking-tools Android libraries

Composite Gradle build consumed by GeoKing apps via `includeBuild`.

| Module | Coordinates | Role |
|---|---|---|
| `:debug-bar` | `fr.geoking.tools:debug-bar` | Floating bug FAB + network/provider/data-usage overlay |
| `:in-app-update` | `fr.geoking.tools:in-app-update` | Play flexible In-App Updates helper + update-available notification (tap → start update) |

See [`skills/gk-debug-bar/SKILL.md`](../skills/gk-debug-bar/SKILL.md) and
[`skills/gk-play-in-app-updates/SKILL.md`](../skills/gk-play-in-app-updates/SKILL.md).
